Prompt chaining — come parlare all'AI per costruire la tua pagina
Prompt
◈ Cos'è il prompt chaining?
💬
Prompt 1
Descrivi l'idea generale. L'AI genera una prima versione.
→
🔍
Guardi il risultato
Cosa non va? Cosa manca? Cosa cambiare?
→
✏️
Prompt 2, 3…
Affini, correggi, aggiungi dettagli. Ogni messaggio costruisce sul precedente.
In parole semplici: è come una conversazione. L'AI ricorda tutto quello che hai scritto prima. Non devi ricominciare da zero — puoi dire "come prima, ma cambia il colore dell'header" e capisce.
◈ Il tuo primo prompt — compila gli spazi
◈ Copia questo template, compilalo e incollalo nell'AI
Voglio creare una pagina web per la ricetta di [nome ricetta]
L'idea creativa è [descrivi il tuo elemento unico — es. "un salame che si snoda come un serpente mentre scorri la pagina"]
La pagina ha [elenca le sezioni nell'ordine — es. "header con titolo, sezione ingredienti, sezione procedimento, footer"]
Quando l'utente [descrivi l'interazione principale — es. "clicca il bottone, appare la lista ingredienti"]
Colori e stile [es. "sfondo crema, testo scuro, accenti rossi, font arrotondato e informale"]
Genera una pagina HTML completa con CSS incluso, pronta da aprire nel browser.
💡 Consigli per prompt efficaci
→Sii specifico: non "fallo bello" ma "sfondo color panna, titolo grande in grassetto"
→Elenca le sezioni nell'ordine in cui devono apparire
→Spiega le interazioni: "quando clicco X succede Y"
→Usa il vocabolario giusto: header, footer, scroll, hover, transizione
📸 Documenta tutto nel dossier
→Screenshot del prompt che hai scritto
→Screenshot del risultato (anche se non è perfetto)
→Nota cosa hai cambiato al tentativo successivo
→Almeno 2 iterazioni documentate per la valutazione
Ricorda: il prompt lo scrivi tu. L'AI è uno strumento — tu sei il designer. Se il risultato non ti convince, non accettarlo. Spiega meglio, chiedi di cambiare, insisti. Un buon prompt è come una buona ricetta: gli ingredienti giusti nell'ordine giusto.

Template prompt chain — Come parlare all'AI
Prompt
◈ Il tuo prompt di partenza — compila gli spazi
◈ Prompt Template — copia, compila e incolla nell'AI
Voglio creare una pagina web per la ricetta di [nome ricetta]
L'idea creativa è [descrivi il tuo elemento creativo — es. "un salame che si snoda come un serpente quando scorri la pagina"]
La pagina ha [descrivi le sezioni — es. "un header con titolo grande, una sezione ingredienti, una sezione procedimento, un footer"]
Quando l'utente [descrivi l'interazione — es. "clicca sul bottone a forma di donut, appare la lista ingredienti"]
Su mobile [descrivi cosa cambia — es. "il menu è in basso, le sezioni sono una sotto l'altra"]
Colori e stile [es. "sfondo crema, testo scuro, accenti arancioni, font arrotondato"]
Genera una pagina HTML completa con CSS incluso, pronta da usare su Glowapp.
◈ Come iterare — cosa fare se il risultato non è quello che volevi
🔁 Tentativo 1
Manda il prompt base. Guarda il risultato. Cosa non va? Scrivi qui:

🔁 Tentativo 2
Aggiungi al prompt: "Il risultato precedente non va bene perché…" poi descrivi cosa correggere.

✅ Tentativo 3
Affina i dettagli. Aggiungi animazioni, cambia colori, modifica il testo. Quando sei soddisfatto: screenshot e salva.

◈ Consigli per un prompt efficace
🎯 Sii specificoNon scrivere "fallo bello". Scrivi "sfondo color panna, titolo in grassetto grande, bottone arrotondato arancione".
📐 Descrivi la strutturaElenca le sezioni nell'ordine in cui devono apparire. L'AI non indovina — devi guidarla.
🖱️ Spiega le interazioni"Quando clicco X succede Y" è il formato giusto. Senza questo l'AI fa una pagina statica.
📱 Ricorda il mobileAggiungi sempre "su mobile le sezioni sono verticali e il menu è accessibile con un tap".
🔄 Usa il contestoNella stessa conversazione, l'AI ricorda i messaggi precedenti. Puoi dire "come prima, ma cambia il colore dell'header".
📸 Documenta tuttoFai screenshot di ogni tentativo, anche quelli sbagliati. Faranno parte del tuo dossier.
Ricorda: Il prompt è tuo. L'AI è uno strumento — tu sei il designer. Se il risultato non ti convince, non accettarlo: spiega meglio, chiedi di cambiare, insisti. Un buon prompt è come una buona ricetta: gli ingredienti giusti nell'ordine giusto.

📸
⚠️ Usa Google Chrome. GoFullPage non funziona su Firefox o Safari. Se il tuo PC non ha Chrome, chiedi alla prof.
1
Installa l'estensione GoFullPage

Apri Chrome e vai all'indirizzo qui sotto. Clicca Aggiungi a Chrome → Aggiungi estensione. La farai una volta sola.

chrome.google.com/webstore → cerca: GoFullPage
2
Apri la tua pagina su GitHub Pages

Vai sul browser e apri la tua pagina pubblicata. L'indirizzo ha questa forma:

nomeutente.github.io/nome-repository
3
Clicca l'icona GoFullPage

In alto a destra nel browser trovi l'icona della fotocamera 📷. Cliccaci sopra. La pagina scorrerà automaticamente e verrà catturata per intero. Aspetta qualche secondo senza toccare niente!

4
Scarica e rinomina il file

Si aprirà una nuova scheda con l'anteprima. Clicca Download PNG. Poi rinomina il file così:

cognome_nome_ricetta.png
Esempio: rossi_marco_carbonara.png
5
Carica su Google Drive

Apri la cartella Drive della classe indicata dalla prof e trascina il file dentro. Fatto! ✅

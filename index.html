💻 Come usare PhoenixCode

  1. Vai su https://phcode.dev
  2. Clicca "Start Coding" (non serve account per provare)
  3. Vedrai 2 box:
    • Editor - a sinistra, dove scrivi il codice HTML
    • Anteprima - a destra, dove vedi il risultato
  4. Scrivi nel box a sinistra e vedrai il risultato in tempo reale!
💡 Trucco: Copia il tuo testo dal Google Doc, poi aggiungi i tag HTML su PhoenixCode!

📌 HTML: Titoli

Cosa sono i titoli?

I titoli servono per organizzare il testo. Ci sono 6 livelli, da H1 (più grande) a H6 (più piccolo).

Come si scrivono:

<h1>Titolo Principale</h1>
<h2>Sottotitolo</h2>
<h3>Sottotitolo più piccolo</h3>

Esempio ricetta:

<h1>Pasta alla Carbonara</h1>
<h2>Ingredienti</h2>
<h2>Preparazione</h2>
💡 Regola importante: Usa UN SOLO H1 per pagina (il titolo principale). Per tutto il resto usa H2, H3, ecc.

📝 HTML: Paragrafi

Cosa sono i paragrafi?

I paragrafi sono blocchi di testo. Ogni paragrafo inizia con <p> e finisce con </p>.

Come si scrivono:

<p>Questo è un paragrafo di testo.</p>
<p>Questo è un altro paragrafo.</p>

Esempio ricetta:

<h2>Preparazione</h2>
<p>Metti l'acqua a bollire in una pentola grande.</p>
<p>Quando bolle, aggiungi il sale e la pasta.</p>
<p>Cuoci per 10 minuti.</p>
💡 Trucco: Ogni volta che vai a capo nel tuo testo, è un nuovo paragrafo!

📋 HTML: Liste puntate

Cosa sono le liste?

Le liste servono per elencare cose. Si usano quando hai più elementi da elencare.

Come si scrivono:

<ul>
  <li>Primo elemento</li>
  <li>Secondo elemento</li>
  <li>Terzo elemento</li>
</ul>

Spiegazione:

  • <ul> = inizia la lista (unordered list)
  • <li> = ogni punto della lista (list item)
  • </ul> = chiude la lista

Esempio ricetta:

<h2>Ingredienti</h2>
<ul>
  <li>400g spaghetti</li>
  <li>150g guanciale</li>
  <li>4 tuorli</li>
  <li>Pecorino q.b.</li>
</ul>
💡 Ricorda: Ogni <li> deve essere dentro <ul>!

🏗️ HTML: Struttura base

Esempio completo ricetta:

<h1>Pasta alla Carbonara</h1>

<p>Una ricetta romana classica e veloce.</p>

<h2>Ingredienti</h2>
<ul>
  <li>400g spaghetti</li>
  <li>150g guanciale</li>
  <li>4 tuorli</li>
</ul>

<h2>Preparazione</h2>
<p>Metti l'acqua a bollire.</p>
<p>Cuoci la pasta al dente.</p>
💡 Il tuo compito: Prendi il tuo testo dal Google Doc e aggiungici i tag HTML che hai imparato!

🖼️ HTML: Inserire immagini

Come funziona:

<img src="indirizzo-immagine" alt="descrizione">

Spiegazione:

  • src = source (dove si trova l'immagine)
  • alt = testo alternativo (cosa mostra l'immagine)

Esempio ricetta:

<h1>Pasta alla Carbonara</h1>
<img src="https://example.com/carbonara.jpg" alt="Piatto di carbonara">

<h2>Ingredienti</h2>
<ul>
  <li>400g spaghetti</li>
</ul>
💡 Importante: L'attributo alt è obbligatorio!

🔍 Dove trovare immagini

Siti con immagini gratis

  • Unsplash → unsplash.com (foto bellissime)
  • Pexels → pexels.com (tantissime foto)
  • Pixabay → pixabay.com (foto, illustrazioni)

Come copiare il link:

  1. Vai su uno dei siti sopra
  2. Cerca l'immagine che ti piace
  3. Clicca sull'immagine
  4. Clicca destro → "Copia indirizzo immagine"
  5. Incolla il link nell'attributo src
⚠️ Attenzione: NON usare immagini da Google Immagini! Usa solo i siti consigliati.

✨ HTML: Dimensioni immagini

Come si scrivono:

<img src="foto.jpg" alt="Descrizione" width="300">

<img src="foto.jpg" alt="Descrizione" width="100%">

Valori comuni:

  • width="300" = 300 pixel di larghezza
  • width="50%" = metà larghezza
  • width="100%" = larghezza piena

Esempio ricetta:

<h1>Tiramisù</h1>
<img src="tiramisu.jpg" alt="Tiramisù" width="100%">

<h2>Ingredienti</h2>
💡 Consiglio: Usa width="100%" per immagini grandi che si adattano a tutti gli schermi.

🏗️ HTML: Head e Body

La struttura completa

Ogni pagina HTML ha questa struttura.

<!DOCTYPE html>
<html lang="it">
<head>
    <title>Nome Ricetta</title>
    <style>
        /* Il CSS va qui */
    </style>
</head>
<body>
    <h1>Ciao mondo!</h1>
    <p>Questa è la mia prima pagina.</p>
</body>
</html>

Cosa significa:

  • <!DOCTYPE html> → Dice al browser che è HTML5
  • <head> → Informazioni sulla pagina (non visibili)
  • <title> → Nome nella scheda del browser
  • <style> → Dove va il CSS
  • <body> → Contenuto visibile
💡 Per ora su PhoenixCode scriviamo solo il contenuto del body!

💬 HTML: Commenti

Perché usare i commenti?

I commenti sono note nel codice che il computer ignora ma che TU puoi leggere.

Come si scrivono:

<!-- Questo è un commento -->

<!-- SEZIONE INGREDIENTI -->
<h2>Ingredienti</h2>
<!-- Lista per 4 persone -->
<ul>
    <li>400g spaghetti</li>
</ul>

Esempio organizzato:

<!-- INTESTAZIONE RICETTA -->
<h1>Pasta alla Carbonara</h1>

<!-- INGREDIENTI -->
<h2>Ingredienti</h2>
<ul>
    <li>400g spaghetti</li>
</ul>

<!-- PREPARAZIONE -->
<h2>Preparazione</h2>
💡 Pro tip: Usa i commenti per creare sezioni nel tuo codice!

🐛 Debug: Errori Comuni

Gli errori più frequenti

❌ PROBLEMA 1: Non vedo niente sulla pagina

Causa: Tag non chiuso

<h1>Carbonara <!-- ERRORE: manca </h1> -->
<p>Ricetta romana

Soluzione: Chiudi TUTTI i tag

<h1>Carbonara</h1>
<p>Ricetta romana</p>

❌ PROBLEMA 2: L'immagine non si vede

Possibili cause:

  • Link sbagliato nell'src
  • Manca l'attributo alt
  • Link non è completo (deve iniziare con https://)

Soluzione: Controlla il link e riprova

❌ PROBLEMA 3: Le liste non hanno i pallini

Causa: <li> fuori da <ul>

<li>Spaghetti</li> <!-- ERRORE -->
<li>Guanciale</li>

Soluzione: Metti i <li> dentro <ul>

<ul>
    <li>Spaghetti</li>
    <li>Guanciale</li>
</ul>

✅ CHECKLIST DEBUG

  1. Tutti i tag sono chiusi?
  2. Gli <li> sono dentro <ul>?
  3. I link delle immagini sono completi?
  4. Hai salvato il file?
  5. Hai ricaricato la pagina (F5)?
💡 Trucco: Se non funziona, rileggi il codice riga per riga cercando tag aperti senza chiusura!

🎨 CSS: Introduzione

Che cos'è il CSS?

CSS significa Cascading Style Sheets. Serve per dare stile alla tua pagina HTML: colori, font, dimensioni!

Analogia: Se l'HTML è la struttura di una casa, il CSS è la decorazione.

Come si aggiunge il CSS?

<head>
    <style>
        h1 {
            color: red;
        }
    </style>
</head>

Sintassi CSS:

selettore {
    proprietà: valore;
}
💡 Il selettore dice COSA modificare (es: h1), la proprietà dice COME (es: color: red)

🌈 CSS: Colori

Proprietà per i colori:

  • color = colore del TESTO
  • background-color = colore dello SFONDO

Esempio:

<style>
    h1 {
        color: darkred;
        background-color: lightyellow;
    }
    
    p {
        color: #333333;
    }
</style>

<h1>Pasta al Pomodoro</h1>
<p>Una ricetta semplice.</p>

Colori comuni:

  • red, blue, green, yellow, orange, purple
  • black, white, gray
💡 Cerca "color picker" su Google per trovare codici colore!

✍️ CSS: Testo

Proprietà principali:

  • font-size = dimensione del testo
  • font-family = tipo di carattere
  • font-weight = grassetto
  • text-align = allineamento

Esempio:

<style>
    h1 {
        font-size: 48px;
        font-family: Arial, sans-serif;
        text-align: center;
    }
    
    p {
        font-size: 18px;
        line-height: 1.6;
    }
</style>
💡 line-height: 1.6 rende il testo più leggibile!

📏 CSS: Spaziature

Margin e Padding

  • margin = spazio ESTERNO
  • padding = spazio INTERNO

Esempio:

<style>
    h1 {
        background-color: #f39c12;
        padding: 20px;
        margin-bottom: 30px;
    }
    
    ul {
        background-color: #ecf0f1;
        padding: 20px;
        padding-left: 40px;
    }
</style>
💡 Usa margin per distanziare elementi, padding per dare spazio interno!

🖼️ CSS: Styling immagini

Proprietà per le immagini:

  • width = larghezza
  • border-radius = arrotondare gli angoli
  • border = aggiungere un bordo

Dimensioni responsive:

img {
    max-width: 100%;
    height: auto;
}

Esempio completo:

<style>
    img {
        width: 100%;
        max-width: 600px;
        border-radius: 15px;
        border: 3px solid #e74c3c;
    }
</style>
💡 border-radius: 50% crea un cerchio perfetto!

📐 CSS: Layout immagini

Posizionare immagini

Con float puoi far "galleggiare" un'immagine e il testo le scorrerà attorno!

Esempio immagine a sinistra:

<style>
    .img-sinistra {
        float: left;
        width: 300px;
        margin-right: 20px;
        border-radius: 10px;
    }
</style>

<img class="img-sinistra" src="impasto.jpg" alt="Impasto">
<p>Inizia mescolando gli ingredienti...</p>

Esempio immagine a destra:

<style>
    .img-destra {
        float: right;
        width: 250px;
        margin-left: 20px;
    }
</style>
💡 Usa margin-right per float left, margin-left per float right!

🔢 Come fare un Sudoku

Cos'è un Sudoku?

Un puzzle logico con una griglia 9x9. Devi riempire ogni cella con numeri da 1 a 9.

📜 LE REGOLE

  1. Ogni riga deve contenere 1-9 (senza ripetizioni)
  2. Ogni colonna deve contenere 1-9 (senza ripetizioni)
  3. Ogni riquadro 3x3 deve contenere 1-9 (senza ripetizioni)

🎯 STRATEGIA BASE

  1. Cerca dove manca un solo numero
  2. Usa il processo di eliminazione
  3. Segna i numeri possibili in piccolo
  4. Inizia dai numeri più frequenti

🌐 SITI UTILI

  • websudoku.com → Sudoku online
  • sudoku.com → Con timer
💡 Il Sudoku migliora concentrazione e logica!

📸 Fare Screenshot

Cos'è uno screenshot?

Una "foto" di quello che vedi sullo schermo.

💻 WINDOWS

Metodo 1: Strumento di cattura

  1. Premi Win + Shift + S
  2. Seleziona l'area con il mouse
  3. Incolla con Ctrl + V

🍎 MAC

Area selezionata

  1. Premi Shift + Cmd + 4
  2. Seleziona l'area
  3. Immagine salvata sul Desktop
💡 Usa gli screenshot per mostrare errori alla prof o salvare risultati!
